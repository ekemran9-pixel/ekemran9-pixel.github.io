# ekemran9-pixel.github.io

Root site for **FabCalc Pro** (https://ekemran9-pixel.github.io/fabcalc/).

- `.well-known/assetlinks.json` — Digital Asset Links that let the Android app (package `com.emran.fabcalc`, a Trusted Web Activity) open the site full-screen without a browser bar. Replace the placeholder with the SHA-256 fingerprint(s) of the signing key(s): the PWABuilder / upload key and, after publishing, the Google Play app-signing key.
- `.nojekyll` — required so GitHub Pages serves the `.well-known` folder.
- `index.html` — forwards visitors to the app.
